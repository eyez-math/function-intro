# מבוא לפונקציה – כלי הוראה ללוח

יישומון HTML עצמאי להוראת מבוא לפונקציה בכיתה.

## פרסום ב-GitHub Pages
1. צור Repository חדש ב-GitHub.
2. העלה אליו את `index.html` (ואפשר גם את `README.md`).
3. עבור ל-Settings → Pages.
4. בחר `Deploy from a branch`.
5. בחר branch בשם `main` ותיקייה `/ (root)`.
6. שמור. לאחר זמן קצר GitHub יציג כתובת לאתר.

אין צורך ב-build, npm או שרת.
